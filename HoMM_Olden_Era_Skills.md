## Общая механика

| Параметр | Значение |
|----------|----------|
| Уровни навыка | **Basic → Advanced → Expert** |
| Поднавыки | Advanced: выбор **1 из 3**; Expert: выбор **1 из 2** |
| Слотов навыков | **8** (включая фракционный) |
| При левелапе | +1 к случайной характеристике + выбор из **3** предложенных навыков |
| Синергии | Активируются автоматически при наличии второго навыка |
| Реликвии | Дают **все** поднавыки сразу для 4 связанных навыков |

### Логика выбора при левелапе

| Слот | Поведение |
|------|-----------|
| **Нижний** | Всегда апгрейд уже изученного навыка |
| **Верхний** | Новый навык (пока слотов < 8) |
| **Средний** | «Джокер» (~50/50: новый навык или апгрейд) |

### Ограничения классов

- **Воины (Might)** — не получают **Thaumaturgy**
- **Маги (Magic)** — не получают **Recruitment** и **Combat**

### Focus (фокус)

Ресурс для способностей героя и существ. Копится от урона в бою. Подробнее: [Combat System](https://wiki.hoodedhorse.com/Heroes_of_Might_and_Magic_Olden_Era/Combat_System).

### Другие способы получить навыки

- Бесплатный апгрейд одного навыка (1 раз за игру)
- **Wise Owl** — фиксированный навык всем посетившим героем
- Объекты на карте: 4 случайных навыка за 2500 золота
- **Infernal Cirque** — до 4 случайных Expert-навыков за 5000 золота каждый
- Полный сброс навыков и уровней — специальный объект или здание в Hive

### Примечания по названиям (редиректы вики)

| Старое / альтернативное | Актуальное |
|-------------------------|------------|
| Offence | **Offense** |
| Intelligence | **Wisdom** (на вики; в требованиях подклассов может фигурировать Intelligence) |
| Ascension | **Righteousness** |
| Call Swarm | **Summon Swarm** |

## Might-навыки

### Offense (Offence)

**Категория:** боевой · **Описание:** увеличивает урон армии

| Уровень | Эффект |
|---------|--------|
| Basic | Базовые атаки: **+15%** урона |
| Advanced | **+20%** |
| Expert | **+25%** |

**Поднавыки (Advanced):**
- **Archery** — Ranged и Long Reach: +15% урона
- **Battle March** — +1 Focus за атаку (×2 с Luck)
- **Battle Frenzy** — +2 Attack за пункт Morale

**Поднавыки (Expert):**
- **Shadow Blades** — +1 Damage
- **Reality Wardens** — +50% урона по призванным врагам (×2 с Nightshade Magic)
- **Firmness** — −15% Defense врагов

**Синергии (даёт Offense):** One For All (Tactics) ×2 · Raw Energy (Sorcery) ×2  
**Реликвия:** Holy Sigil of The Second Man

**Категория:** боевой · **Описание:** бонусы при Wait / Skip

|---------|---------------|----------------|
| Basic | +20% | +20% |

## Способности существ

Единого справочника нет — описаны на страницах юнитов и фракций.

### Типы

| Тип | Описание | Примеры |
|-----|----------|---------|
| **Passive Traits** | Постоянные, без Focus | Swift Strike, Parry, Sharpshooter, Magic Immunity I–V, Absolute Resistance |
| **Active Abilities** | За Focus в бою | Summoning Rite, Refract and Reflect, Banish Summons |
| **Alternative Attacks** | Вместо обычной атаки | Whirlwind Strike, Sweeping Strike, Dragonbreath Strike |

### Частые пассивки

- **Swift Strike** — враги не контратакуют
- **Parry** — контратака до удара врага
- **Sharpshooter** — полный Ranged без штрафа дистанции
- **Magic Defense / Magic Immunity I–V** — иммунитет к заклинаниям/способностям по tier
- **Absolute Resistance / Pure Resistance** — иммунитет ко всему маг. урону
- **Embodiment** — не оставляет тело, иммунитет к Necromancy и «Raise Dead»
- **Disdain** — снижение получаемого урона по типу атаки

### Частые активные способности

- **Summoning Rite** (Schism) — призыв из трупа
- **Banish Summons** — снятие всех призванных
- **Nullify** — снятие всех эффектов с цели
- **Bubble of Silence** — соседи не могут использовать способности
- **Leap / Sticky Tongue** — манёвры на поле боя
